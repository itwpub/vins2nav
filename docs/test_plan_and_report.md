# 测试方案与报告模板

## 1. 测试目标

验证系统在真实环境中的功能完备性、性能指标与长期稳定性。

## 2. 测试环境

- 机器人平台：_______
- 相机：OAK 4Dpro
- ROS 版本：Jazzy
- 地图类型：2D/3D
- 场景：室内走廊 / 开阔区 / 动态人群区

## 3. 功能测试

### 3.1 避障测试

- **步骤**：设置静态障碍、动态障碍，发送导航目标。
- **预期**：规划路径绕障，速度平滑，无碰撞。
- **记录项**：成功率、最小障碍距离、急停次数。

### 3.2 路径规划测试

- **步骤**：多个目标点循环导航（N>=20）。
- **预期**：可达点规划成功率 > 95%。
- **记录项**：规划耗时、路径长度、重规划次数。

### 3.3 目标到达测试

- **步骤**：不同距离（2m/5m/10m）目标点到达。
- **预期**：到达误差满足阈值（位置 < 0.20m，角度 < 10°）。

## 4. 性能测试

### 4.1 定位精度

- **指标**：ATE、RPE
- **方法**：与真值（激光定位/动作捕捉）对比。

### 4.2 导航效率

- **指标**：平均到达时间、平均速度、绕行率。
- **方法**：同一路径重复 10 次求统计值。

### 4.3 建图质量

- **指标**：地图完整度、闭环误差、重复性。
- **方法**：多轮建图对比重叠区域一致性。

## 5. 稳定性测试

### 5.1 长时间运行（8h/24h）

- **观测**：CPU、内存、话题频率、节点重启次数。
- **通过条件**：无崩溃，导航成功率下降不超过 5%。

### 5.2 异常恢复

- 断开/恢复相机
- 临时遮挡镜头
- 局部光照突变

预期系统可恢复并在限定时间内重新稳定。
